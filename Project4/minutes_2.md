Decisions
The application will maintain its three main features from Project 3.
The assignment management, completion tracking, and course organization features will be treated as separate application components.
A shared cloud-based database will store application information.
The Docker container will include the application code, runtime environment, dependencies, and configuration files.
Each component will have its own responsibilities and database requirements.
