# CSCI4221ASU-Fall26_G3
Product Vision Statement
For college students who want an easier way to manage their schoolwork, Student Task Tracker is a web-based application that organizes assignments, courses, deadlines, and completion progress in one convenient location. Instead of relying on a handwritten to-do list, students can add and update assignments, sort tasks by course, and keep track of upcoming due dates. The purpose of the application is to help students stay organized and manage their academic responsibilities more effectively.

Proposed Features
Create assignments by entering the course, assignment name, and due date.

Display assignments in an organized task list.

Modify existing assignments when information changes.

Remove assignments that are no longer needed.

Mark assignments as completed.

Sort or filter assignments based on course or completion status.

Store assignments locally in the browser so the information remains available after closing the website.
