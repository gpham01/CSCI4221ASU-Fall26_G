Project 3: Features, Personas, Scenarios, and User Stories
Section 1: Feature
Feature 1: Add and Manage Assignments
The Student Task Tracker allows students to add assignments with a title, course, and due date. Students can also edit or delete assignments when necessary. This feature helps students keep their schoolwork organized.

Feature 2: Track Assignment Completion
Students can mark assignments as completed or incomplete. This feature helps users understand which assignments they have finished and which tasks still need attention.

Feature 3: Organize Assignments by Course
Students can organize or filter assignments by course. This feature helps students focus on the work for a particular class instead of searching through every assignment.

Section 2: Persona
Persona 1: Busy College Student
Name: Alex Johnson

Background: Alex is a college student taking several classes while working part-time.

Goals: Complete assignments on time and maintain good grades.

Needs: Alex needs a convenient way to organize assignments and keep track of due dates.

Persona 2: First-Year College Student
Name: Taylor Smith

Background: Taylor is new to college and is learning to manage assignments from multiple classes.

Goals: Develop good study habits and avoid missing deadlines.

Needs: Taylor needs a simple task list that shows assignments and their completion status.

Persona 3: Student with Family Responsibilities
Name: Jordan Lee

Background: Jordan attends college while balancing family responsibilities and schoolwork.

Goals: Manage time effectively and complete coursework.

Needs: Jordan needs to organize tasks by course and quickly identify unfinished assignments.

Section 3: Scenario
Scenario 1: Adding an Assignment
Alex receives a new assignment from a college instructor. Alex opens Student Task Tracker, enters the assignment title, course, and due date, and saves it. The assignment appears in the task list so Alex can plan when to complete it.

Scenario 2: Checking Assignment Progress
Taylor finishes an assignment and opens Student Task Tracker. Taylor marks the assignment as completed and reviews the remaining incomplete assignments to decide what to work on next.

Scenario 3: Finding Assignments for a Course
Jordan wants to finish work for a particular class. Jordan opens Student Task Tracker and organizes or filters the assignments by course. Jordan reviews the unfinished work and decides which task to complete first.

Section 4: User Story
User Story 1: Add an Assignment
As a college student, I want to add an assignment with its course and due date so that I can keep track of my schoolwork.

Acceptance Criteria:

The student can enter an assignment title.
The student can enter or select a course.
The student can select a due date.
The assignment appears in the task list after it is saved.
User Story 2: Mark an Assignment as Completed
As a student, I want to mark an assignment as completed so that I can track my progress.

Acceptance Criteria:

The student can mark an assignment as completed.
The assignment's status is updated.
Completed assignments can be distinguished from incomplete assignments.
User Story 3: Organize Assignments by Course
As a college student taking multiple courses, I want to organize or filter assignments by course so that I can focus on work for a particular class.

Acceptance Criteria:

The student can identify the course associated with an assignment.
The student can view assignments organized by course if this functionality is supported.
The student can find assignments that still need to be completed.
